# Cours compilé : « La mécanique par la simulation »

Cours à **six niveaux** (vulgarisation, intéressé, collège, lycée, étudiant L1-L3, doctorant/chercheur) pour expliquer à des non-initiés tout le domaine Mécanique de PhysicsLab 3D (modules M0 à M7), avec **64 exercices corrigés**.

| Fichier | Format | Usage |
|---|---|---|
| `La-mecanique-par-la-simulation.docx` | Word | version modifiable (table des matières à jour : clic droit sur la table, « Mettre à jour le champ », si vous changez la pagination) |
| `La-mecanique-par-la-simulation.pdf` | PDF, 75 pages | version à distribuer ou à projeter |

Contenu : avant-propos et mode d'emploi, 7 chapitres (calculer pas à pas ; le ressort ; le pendule et le chaos ; la gravitation ; frottements, chocs et rebonds ; les solides qui tournent ; mille étoiles sur une carte graphique), conclusion en dix idées, annexe A (corrigés), B (glossaire), C (formulaire et valeurs de référence), D (utiliser le logiciel), E (références).

Chaque chapitre déroule les six niveaux, un encadré « Dans le logiciel » avec une capture, des exercices rangés par niveau et un encadré « À retenir ». Les chiffres viennent de l'exécution du logiciel (voir `docs/devlog/`) ; les figures sont tracées à partir des solveurs du projet.

Le générateur (texte du cours, mise en page, figures, calcul des réponses) est dans `tools/cours/`.
